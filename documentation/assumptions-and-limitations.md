# Assumptions and Limitations

## Assumptions

### Processed source dataset

The dashboard assumes the source dataset has already been cleaned, validated and aggregated consistently.

Each record represents:

- one police force
- one month
- one crime category

### Category comparability

The analysis assumes crime-category definitions and recording conventions are sufficiently comparable across the four forces and the 36-month reporting period.

### Population denominator

Population is held constant using the selected **2024 estimate** so that population-adjusted rates remain comparable throughout the reporting period.

## Limitations

### Recorded crime is not total crime

Recorded crime does not represent every crime occurring in an area.

Figures can be influenced by:

- whether offences are reported
- police recording practices
- enforcement activity

### Force-level aggregation

Force-level analysis can hide substantial differences between neighbourhoods within the same police-force area.

### Three-year seasonal window

Three years of monthly data is useful for identifying operational patterns, but it is not sufficient to establish a permanent long-term seasonal trend.

Seasonal findings should therefore be treated as planning signals rather than causal conclusions.

### Scope

The report is limited to the offence categories included in the reporting dataset.

The dashboard does not include:

- crime outcomes
- stop-and-search activity

## Interpretation principle

The dashboard should be used to **prioritise and investigate**, not to prove why a change occurred.
