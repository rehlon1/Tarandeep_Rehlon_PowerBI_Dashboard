# Power BI Report

The original Power BI report is included in this folder as:

`Tarandeep_Rehlon_Crime_Database_Dashboard.pbix`

## Report pages

The PBIX contains two report pages:

1. **Crime Overview**
2. **Crime Investigation & Seasonality**

The model contains two visible tables:

- `Police Crime Data - OUTPUT`
- `DateTable`

## Crime Overview

The page contains 11 report visuals, including:

- KPI cards
- Monthly Crime Trend
- Average Monthly Crime Rate per 1,000 Residents
- Top 5 Crime Types by Recorded Volume
- Recorded Crime and Officer Strength by Reporting Year
- Police force slicer
- Crime category slicer
- Date slicer

## Crime Investigation & Seasonality

The page contains 7 report visuals, including:

- Seasonal Crime Patterns by Reporting Year
- Crime Rate and Employment Deprivation by Police Force
- Monthly Trends for Top 5 Crime Types
- Average Officers per 100,000 KPI
- Average Monthly Crime Rate per 1,000 KPI
- Police force slicer
- Crime category slicer

## Report design

The dashboard is aimed at police leadership teams rather than technical analysts.

The report is intentionally structured to support a simple workflow:

```text
Monitor
   ↓
Compare
   ↓
Investigate
   ↓
Act
```

The overview page provides fast monitoring and comparison. The investigation page then allows a selected force or category to be explored in more detail.
